03 / inspect the search policy

One deterministic order.
No invisible tie-break.

Ascending f = g + h, then ascending g, then ascending state mask. Null h/f means infinity and sorts last. Actions are considered in index order. Equal-cost alternatives do not replace a label; only strict g improvements do. The base inspector separately retains all optimal-plan ties.

Admissibility compares every state against exact remaining distance. Consistency checks every applicable real edge with unit cost. An infinite true distance permits any finite estimate. Infinity-to-finite edges can violate consistency. These checks are diagnostics, never an extra search ordering signal.
