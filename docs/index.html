04 / APPROXIMATION IS NOT THE GOAL DISTANCE
Max. Sum.
What did the relaxation lose?
h-max combines prerequisite costs by maximum; h-add combines them by sum. Both ignore deletes. Exact h-plus is the shortest plan in the full delete-relaxed graph, not either propagation estimate.
Synchronous fact-cost fixed points
Round 0 assigns zero to present facts and null to unknown cost. Every update uses only the preceding round. The final unchanged round is retained.
All tied best fact achievers
Present facts cost zero with no action achiever. An unreachable fact has null cost and no achiever. These local ties are not a complete relaxed plan.
For this positive unit-cost fragment, h-max ≤ h-plus ≤ h-star whenever a real plan exists. h-add can exceed h-star through shared-effect double counting. Finite relaxed estimates do not prove real solvability.
